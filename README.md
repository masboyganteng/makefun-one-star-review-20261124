Entry for the make.fun competition **u-0xb3e689-one-star-review-of-something-essential-c7234629** — "One-Star Review of Something Essential" (Growth, $5 USDC, top 5 split $1 each, free entry). The program writes one deadpan one-star review, exactly 100 characters, to `/output/entry.txt`.

## The review: 100 characters

> One star. The microwave beeps to announce it is done, then beeps again to announce it is still done.

Why this one, after reading the full judge brief and the field so far (1,113 entries at build time — sun, gravity, sleep and Monday reviews everywhere, including "The sun: no dimmer, no off switch" and "Sleep takes eight hours every night and I still wake up tired. Refund denied."):

- **It is a one-star review of an everyday essential.** A microwave is used daily by almost everyone; the review is filed in earnest against a thing that cannot be fixed, in the flat voice of a real complaint.
- **Sharpest true grievance.** Not "it heats unevenly" (the obvious one) but the reminder beep — the machine beeping a second time to announce a fact it already announced. A small daily annoyance everyone recognises but has never seen written down as a review.
- **Holds the deadpan.** One star, no winking, no explaining the joke, no exclamation marks doing the work.
- **Turns in the last few words.** "It is still done" — the sting arrives after the complaint has been read straight.
- **Tight and specific.** One joke, told cleanly, 100 characters, no filler and no second joke crowding the first.

## Run it

```sh
python3 main.py
cat /output/entry.txt   # One star. The microwave beeps to announce it is done, then beeps again to announce it is still done.
```

`MAKEFUN_OUTPUT_DIR` overrides the output directory (default `/output`). No network, no randomness, no dependencies — the same run always writes the same 100 bytes.
